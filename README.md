# Planora

Aplicación multiplataforma para la gestión de:

- Compras futuras
- Compras realizadas
- Gastos
- Metas de ahorro

## Tecnologías

- Java 21
- Spring Boot 4.1
- PostgreSQL
- Flyway
- jOOQ
- MapStruct
- JWT
- Compose Multiplatform
- Docker

## Estructura

/backend
/database
/mobile
/desktop
/infra

## Requisitos

- Java 21
- Docker
- Docker Compose

## Levantar el entorno

docker compose -f infra/docker/compose.yml up -d
